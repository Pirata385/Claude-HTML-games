# Animações

Animations shown in the **Animações** tab of the root menu (`index.html`). Each animation has its own folder here, with a self-contained `index.html` and a `README.md`. There is no build step and nothing to install.

| Animation | Folder | Description |
| --- | --- | --- |
| Motion Showcase | [`motion-showcase/`](motion-showcase/) | A motion design demo that cycles through nine art styles with animated transitions. |
| Operação Vermelho | [`bloons-sniper/`](bloons-sniper/) | A one-minute Bloons TD6 fan short: a tense rooftop sniper scene that ends at a birthday party. |

## Adding an animation

1. Create a folder here with an `index.html` and a `README.md`. Link back to the menu with `../../index.html#animacoes` so the menu opens on this tab.
2. Add an entry to the `ANIMATIONS` array in the root `index.html`.
3. Add a row to the table above and to the **Animações** table in the root `README.md`.
